# Итерация 10

## Полировка: слот-анимация, Reka UI, копирайт, мобильный хедер, UX-фиксы

> Оператор: Claude (Cowork). Серия итеративных правок по фидбеку PO. Сборку/тесты — у PO на хосте.

## Сделано

### Слот — анимация выигрыша
- Делится на N **равных вертикальных полос** по числу линий (пара → 2 по 50%, тройка → 3 по 33%), за монстром, с разделителями.
- Каждая полоса — поток кода с направлением **вниз/вверх/вниз** (обычная/реверс/обычная) — `MatrixPanelBackdrop.drawMatrix` (per-band dir) + `playSplit`. Куб не тронут (`play()`).

### Reka UI вместо ручных компонентов (ADR-019)
- Локаль-пикер → `DropdownMenu`, цель кубика → `Slider`, under/over → `RadioGroup`. Обёртка `BrutalTabs` готова к подключению.

### Копирайт
- Вычищены машинные/битые строки во всех 3 локалях: tagline, `← Лobby`, `задеployен`, code-switching описания игр, SEO. Брутал-тон сохранён.

### UX-фиксы (по фидбеку)
- Тост не наезжает на ✕; авто-роллы: тост-итог + скролл к игре + бар адаптивен; скорость = сегментированный radio; ∞ = чекбокс ON/OFF.
- Системные стрелки у number-инпутов убраны; брутал-чекбоксы `.bw-check`; дропдаун локали поверх хедера (`[data-reka-popper-content-wrapper]` z-index).
- Блок результата спрятан за чекбокс «Показывать результат» (дублировал кубик/тост).
- Баланс слева / ставка справа, выровнены по центру.
- **Мобильный хедер** — 2 строки: логотип+тема+язык / кнопка авторизации (`w-full`), уменьшена высота.
- Кнопка Roll/Spin не прыгает по высоте; лого → matrix-переход домой.
- Чинён латентный краш тостов в `ConnectButton` (как ранее в играх).

### Критические баги (в предыдущих заходах ит.10)
- **Слот никогда не выигрывал** — RNG-фикс (per-reel nonce stride) в `lib.rs` + `rng-verify`, ~44% пар. **LIVE требует передеплоя программы.**
- **Деплой Netlify** — env-плагин не фатален при пустом env → FUN-главная грузится.
- **ACCESS DENIED** переносится по словам.
